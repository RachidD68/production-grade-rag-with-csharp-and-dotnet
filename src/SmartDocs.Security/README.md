# SmartDocs.Security

Security defences for the **SmartDocs** RAG stack — the companion library to
*Production-Grade RAG with C# and .NET*.

The building blocks behind the book's red-team suite: input sanitization, heuristic
prompt-injection detection, output PII redaction, tenant isolation, rate limiting, and
embedding-anomaly detection.

## Install

```bash
dotnet add package SmartDocs.Security
```
