# SmartDocs.Routing

Query routing for the **SmartDocs** RAG stack — the companion library to
*Production-Grade RAG with C# and .NET*.

Classifies an incoming query and dispatches it to the right retrieval strategy. A
support package consumed by the MCP server and higher composition layers.

## Install

```bash
dotnet add package SmartDocs.Routing
```
