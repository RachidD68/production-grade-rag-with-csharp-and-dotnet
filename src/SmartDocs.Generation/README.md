# SmartDocs.Generation

Answer generation for the **SmartDocs** RAG stack — the companion library to
*Production-Grade RAG with C# and .NET*.

The prompt-template engine, the grounded `RagPipeline`, and the citation/audit shapes
that turn retrieved context into a cited answer. A support package consumed by the
evaluation and operations layers.

## Install

```bash
dotnet add package SmartDocs.Generation
```
