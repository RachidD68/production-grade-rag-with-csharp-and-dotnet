# 0013 — Upgrade MAF from 1.11.1 to 1.13.0 (final pre-ship pass, July 2026)

Date: 2026-07-15

## Status

Accepted (supersedes ADR-0012, which remains the record of the 1.10.0 → 1.11.1
bump). This is the last dependency move before the book ships.

## Context

Microsoft released **MAF `dotnet-1.12.0`** and **`dotnet-1.13.0`** after ADR-0012;
the current stable patch on NuGet is **`1.13.0`** (July 3 2026), with the
preview-only siblings at **`1.13.0-preview.260703.1`**. Shipping a 2026 book pinned
to `1.11.1` while a reader's first `dotnet add package Microsoft.Agents.AI` resolves
to `1.13.0` is the same first-day-old-on-the-shelf drift ADR-0010/0011/0012 guarded
against, so the baseline moves to `1.13.0` before print.

The `1.12`/`1.13` line's headline changes are in surfaces this codebase does not
touch: the **Skills API** stabilized (GA at 1.13), **Foundry Hosting** moved to
per-user session isolation with Responses v2, the **OpenAI-hosting options** mapping
was refactored, and **FileAccess/FileMemory** were reworked. SmartDocs uses the core
agent/`IChatClient`/`IEmbeddingGenerator` surfaces and the Ch20 eval stack, none of
which changed in a breaking way — confirmed by build + tests below.

## Decision

Pin to the latest stable patch:

- `Microsoft.Agents.AI` / `.Abstractions` / `.OpenAI` / `.Workflows` → **`1.13.0`**.
- `Microsoft.Agents.AI.Foundry` / `.A2A` / `.Hosting.A2A.AspNetCore` →
  **`1.13.0-preview.260703.1`** (these sub-packages remain preview-only at the 1.13
  milestone).
- `Microsoft.Agents.AI.Mem0` stays **`1.0.0-preview.251028.1`** (its own line; no
  newer release).

`Microsoft.Extensions.AI*` / `…VectorData.Abstractions` stay at **`10.7.0`**: MAF
`1.13.0` declares a `Microsoft.Extensions.AI` floor of `10.6.0`, which the existing
`10.7.0` pin already satisfies, so no Extensions.AI change is required. The database
drivers (`Neo4j.Driver 6.2.1`, `Qdrant.Client 1.18.1`), `OpenAI 2.11.0`, the
`10.0.9` platform cohort, `ModelContextProtocol 1.4.0`, and the `Microsoft.OpenApi
2.7.5` audit pin all stay put — none has a newer clean patch that this bump requires.

## Consequences

- **No production-code changes.** `1.11.1 → 1.13.0` is a clean drop-in for this
  codebase: `dotnet build -c Release` is 0 warnings / 0 errors (warnings-as-errors),
  and the full suite passes — **443 tests** (361 unit + 67 security + 15 integration;
  1 skipped). The `1.12`/`1.13` changes did not affect any API this code's surface
  touches; the Ch14/15/19 API-detail claims (`ChatOptions.Instructions`, the
  `session` run parameter, `MessageAIContextProvider`) still hold, since the samples
  that use them build against `1.13.0`.
- **One test hardened (not a regression).** `CostTrackingTests` attaches a
  `MeterListener` to the process-global `CostMeter` and, before this pass, summed
  **every** `smartdocs.cost.usd` measurement during the act window — so a cost
  recording from another test class running in parallel could inflate the total. The
  1.13 build's parallel timing surfaced this latent isolation flake (the embedding
  test read 2120 tokens instead of its mock's 2000). Fixed by scoping `CaptureCost`
  to the test's own tenant id; test-only change, no behaviour change to the meter.
- **Book baseline.** The manuscript's install-baseline version strings move
  `MAF 1.11.1 → 1.13.0`, and the Ch02 "what's new" delta list gains `1.12.0` and
  `1.13.0` entries. Historical "introduced in 1.4.x–1.11" notes and the Qdrant/Neo4j
  *server* version references are left untouched. The M.E.AI `10.7.0` strings stay
  (floor unchanged).
