# 0010 — Upgrade MAF from 1.6.1 to 1.8.0 (June 2026)

Date: 2026-06-03

## Status

Accepted

## Context

Microsoft released **MAF `dotnet-1.8.0`** on June 2, 2026. The companion code and the book text both still pin **`1.6.1`** (May 14, 2026). The window between the two releases spans two intermediate versions — `1.6.2` (May 22) and `1.7.0` (May 26) — and **102 commits**, including 4 breaking changes.

Shipping the book at `1.6.1` would mean every reader's first `dotnet add package` resolves to a newer minor than the version the book describes. That is the kind of small-but-corrosive drift that makes a 2026 technical book feel old on its first day on a shelf.

### Breaking changes between 1.6.1 → 1.8.0

Verified against this codebase via exhaustive `grep` over `src/`, `tests/`, `tools/`, `samples/`, and the chapter `render.js` sources. Each row records whether the change touches anything we ship.

| # | Release | Breaking change | Impact here |
|---|---|---|---|
| 1 | `1.6.2` | `SubAgents` → `BackgroundAgents` rename | None — the symbol `SubAgents` does not appear in this codebase or in any chapter. |
| 2 | `1.7.0` | `AgentSkill` API refactored to async resource / script lookup (PR #6030) | None — the book covers MCP-based and inline tool authoring, not the declarative `AgentSkill` surface. |
| 3 | `1.8.0` | Code-gen removed from declarative workflows (PR #6095) | None — Ch 19 uses the programmatic `Workflow` builder (`.AddConditionalEdge`, `.AddParallelEdges`, `.AddJoinNode`). Ch 19's "Code Mode" is an unrelated concept (LLM-written code against a constrained API, not declarative-workflow code generation). |
| 4 | `1.8.0` | `AgentFileSkillsSource` refactored to depth-based discovery + predicate filters (PR #6109) | None — same as row 2, declarative skills are not used. |

The carry-over caveat from the 1.3.0 → 1.6.1 jump still applies: with `Microsoft.Agents.AI.OpenTelemetry` referenced, the underlying `IChatClient` is auto-wired with `OpenTelemetryChatClient`. Manually wrapping it produces duplicate spans. This was noted in the 1.6.1 bump and remains true at 1.8.0; no code change is required because we already do not wrap.

### New surfaces in 1.7 / 1.8 the book should mention

Verified against the same `grep` — none of these symbols are mentioned in the current text, so each one is an additive callout, not a rewrite.

| Feature | PR | Chapter that picks it up |
|---|---|---|
| `FoundryChatClient` promoted to public + file/vector-store helpers + `ToPromptAgentAsync` | #5940 (1.7.0) | Ch 02 (toolkit) |

### A2A package status at 1.8.0

`Microsoft.Agents.AI.A2A` and `Microsoft.Agents.AI.Hosting.A2A.AspNetCore` are still preview at the 1.8.0 milestone. The most recent preview is `1.8.0-preview.260528.1` (verified against `api.nuget.org/v3-flatcontainer/microsoft.agents.ai.a2a/index.json` on the date of this ADR). There is no `1.8.0` GA for A2A.

## Decision

Pin the stable packages to **`1.8.0`** and the A2A preview packages to **`1.8.0-preview.260528.1`** in `Directory.Packages.props`.

```xml
<PackageVersion Include="Microsoft.Agents.AI" Version="1.8.0" />
<PackageVersion Include="Microsoft.Agents.AI.Abstractions" Version="1.8.0" />
<PackageVersion Include="Microsoft.Agents.AI.OpenAI" Version="1.8.0" />
<PackageVersion Include="Microsoft.Agents.AI.Foundry" Version="1.8.0" />
<PackageVersion Include="Microsoft.Agents.AI.Workflows" Version="1.8.0" />
<PackageVersion Include="Microsoft.Agents.AI.OpenTelemetry" Version="1.8.0" />
<PackageVersion Include="Microsoft.Agents.AI.A2A" Version="1.8.0-preview.260528.1" />
<PackageVersion Include="Microsoft.Agents.AI.Hosting.A2A.AspNetCore" Version="1.8.0-preview.260528.1" />
```

No code changes follow from this bump. The quality bar (`dotnet build` warnings-as-errors, `dotnet test`, `dotnet format --verify-no-changes`, and the banned-API grep from `rag-in-dotnet-conventions.md`) must remain green.

The book text bumps in a sibling commit: 11 version-string anchors across 6 chapters move from `1.6.1` to `1.8.0`, and 4 short callouts are added for the new surfaces listed above.

This ADR also corrects a small documentation bug in the 1.6.1 bump: `Directory.Packages.props` line 32 referenced `0007-maf-1.6.1-upgrade.md`, but ADR-0007 is the IVectorStore decision. That reference was a typo; this ADR is the first decision record for any MAF version bump. The comment is updated to point here.

## Consequences

**Positive**:
- Readers running `dotnet add package Microsoft.Agents.AI` in mid-2026 resolve to the same version the book describes.
- The book picks up four real and useful surfaces (public `FoundryChatClient`, MCP long-running tasks, `ClaimsIdentity` session scoping, Handoff Orchestration parity) without any reader-facing code rewrite.
- The companion-code quality bar stays green because none of the breaking changes affect what we ship.

**Negative / accepted trade-off**:
- The `1.8.0` A2A SKU is still preview. We were already on a preview suffix at `1.6.1`, so the risk profile does not change.
- The book is now two minors ahead of any reader who already started reading at `1.6.1`; the 1.6.1 → 1.8.0 history is captured in the chapter text rather than in errata.

**Verification**:
- `dotnet build RAG-in-DotNet.slnx` — 0 warnings, 0 errors.
- `dotnet test RAG-in-DotNet.slnx --no-build` — 154 passed.
- `dotnet format --verify-no-changes` — exit 0.
- Banned-API grep returns empty.
- All companion samples (`samples/Ch01_…` through `samples/Ch25_…`) build and run; output of the 6 deterministic ones matches the 1.6.1 baseline.
