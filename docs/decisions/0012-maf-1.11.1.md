# 0012 — Upgrade MAF from 1.10.0 to 1.11.1 (pre-print pass, June 2026)

Date: 2026-06-26

## Status

Accepted (supersedes the version baseline in ADR-0011, which remains the record
of the 1.8.0 → 1.10.0 reconciliation and the revision pass).

## Context

Microsoft released **MAF `dotnet-1.11.x`** after ADR-0011; the current stable
patch on NuGet is **`1.11.1`** (the `1.11.x` preview siblings are
`1.11.1-preview.260625.1`). Shipping a 2026 book pinned to `1.10.0` while a
reader's first `dotnet add package Microsoft.Agents.AI` resolves to `1.11.1` is
the same first-day-old-on-the-shelf drift ADR-0010/0011 guarded against, so the
baseline moves to `1.11.1` before print.

## Decision

Pin to the latest stable patch:

- `Microsoft.Agents.AI` / `.Abstractions` / `.OpenAI` / `.Workflows` → **`1.11.1`**.
- `Microsoft.Agents.AI.Foundry` / `.A2A` / `.Hosting.A2A.AspNetCore` →
  **`1.11.1-preview.260625.1`** (these sub-packages remain preview-only).
- `Microsoft.Agents.AI.Mem0` stays **`1.0.0-preview.251028.1`** (its own line; no
  newer release).
- Alongside, the unrelated database drivers move to their current stable patches:
  `Neo4j.Driver` `6.1.2 → 6.2.1` (no breaking change within the 6.x major) and
  `Qdrant.Client` `1.17.0 → 1.18.1`.

`Microsoft.Extensions.AI*` / `…VectorData.Abstractions` stay at **`10.7.0`**: MAF
`1.11.1` declares a `Microsoft.Extensions.AI` floor of `10.6.0`, which the
existing `10.7.0` pin already satisfies, so no Extensions.AI change is required.

## Consequences

- **No code changes.** `1.10.0 → 1.11.1` is a clean drop-in for this codebase:
  `dotnet build -c Release` is 0 warnings / 0 errors and all 443 tests pass
  unchanged. The `1.11` line introduced no compile- or behaviour-breaking change
  that this code's API surface touches (the Ch14/15/19 API-detail claims —
  `ChatOptions.Instructions`, the `session` run parameter, `MessageAIContextProvider`
  — still hold, since the samples that use them build against `1.11.1`).
- **Book baseline.** The manuscript's install-baseline version strings move
  `MAF 1.10.0 → 1.11.1` (and the `Neo4j.Driver` / `Qdrant.Client` pins follow),
  while historical "introduced in 1.6.x–1.9.0" notes and the Qdrant/Neo4j *server*
  version references (Qdrant 1.7/1.10, Neo4j 5.26) are left untouched.
